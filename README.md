# ANN Heart Disease Prediction with Voice Assistant

## About the Project
An Artificial Neural Network (ANN) based machine
learning application designed to predict heart
disease risk using user-provided health parameters.

## Features
- ANN-based Heart Disease Prediction
- Interactive React Frontend
- Python Backend API
- Voice Assistant Integration
- User-friendly Interface
- Real-time Prediction Results

## Technologies Used
- Python
- TensorFlow
- Scikit-learn
- React.js
- JavaScript
- FastAPI / Flask (as applicable)

## Project Architecture
- Frontend: React
- Backend: Python
- Model: Artificial Neural Network
- Deployment: Vercel and Render
